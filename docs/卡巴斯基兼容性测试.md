# 卡巴斯基兼容性测试（离线可读）

> 测试中要注销校园网，会断网。这份说明在本地，断网也能看。
> 目的：找出卡巴斯基到底拦的是哪一步。**每一步做完都记一下卡巴斯基有没有弹窗。**

测试文件：`D:\CampusLogin-test\CampusLogin.exe`
MD5：`46e56d487804f2278682f83f3633b20d`（卡巴斯基报毒时会显示 MD5，可以对一下是不是这个文件）

---

## 准备

- 卡巴斯基保持正常开启，**不要**加任何信任或排除。
- Clash Verge 照常开着，2.2.2.2 的直连规则保持不变。
- 这一版程序**不会**复制自己，**不会**写注册表，启动时**不会**碰任何密码文件。

## 测试 ①：只登录，不设开机自启

1. 双击 `D:\CampusLogin-test\CampusLogin.exe`，会弹出"账号设置"窗口。
2. **手动输入**学号和密码。左边那个"导入旧版脚本保存的账号"先**不要点**。
3. **取消勾选「开机自动运行」**，然后点「保存」。
4. 右下角托盘会出现一个 Wi-Fi 图标（可能在 `^` 收起区里）。绿色表示在线。
5. 等 1 分钟，看卡巴斯基有没有反应。 → **记录 ①-a**
6. 模拟掉线：浏览器打开 `http://2.2.2.2`，点 **注销**。
7. 在托盘图标上点一下 → 「立即检查」（不点的话最多等 60 秒也会自己检查）。
8. 正常情况：图标变黄后又变绿，右下角提示"校园网已自动登录"，网络恢复。 → **记录 ①-b**（这一步会解密密码并联网发送，是重点）

## 测试 ②：加上开机自启

1. 托盘图标 → 勾选「开机自动运行」。
   - 可以按 Win+R 输入 `shell:startup` 回车，里面应该多了一个"校园网自动登录"快捷方式。
2. 等 1 分钟。 → **记录 ②-a**
3. 再注销一次（同 ①-6、①-7），看它能不能自动登录。 → **记录 ②-b**

## 测试 ③：重启电脑

1. 重启电脑，登录 Windows 后**什么都不要点**，等 30 秒左右。
2. 托盘应该自动出现图标。如果已经是绿色（在线），就再注销一次，看它能不能自动登录。 → **记录 ③**

---

## 卡巴斯基报毒的话

- 记下：**是第几步**、**检测名称**（比如 `PDM:Trojan.Win32.Generic`）、**对象路径**、**MD5**。
- 断网了也不要慌：浏览器打开 `http://2.2.2.2` 手动登录即可，跟这个程序没关系。
- 卡巴斯基拦截后可能会自动回滚，比如删掉启动文件夹里的快捷方式，这是正常的。

## 测完以后

把 ①-a、①-b、②-a、②-b、③ 的结果（"没反应"或者报毒信息）发给开发者（提 Issue 即可）。
另外打开 `%LOCALAPPDATA%\CampusLogin\campus-login.log`，把内容一起发过来。**日志里没有密码**（但有你的学号和本机 IP），可以直接发。

想停止测试：托盘图标 → 「退出」。想把它留下的东西全部清掉：托盘图标 → 「清除数据并退出…」，然后删除 `D:\CampusLogin-test` 文件夹。
